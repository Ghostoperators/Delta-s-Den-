# 🇮🇳 Delta's Den

Delta's Den is a tribute website dedicated to the Indian Armed Forces. The website provides information about the leadership, structure, and significance of the Indian Army, Indian Air Force, and Indian Navy while showcasing patriotic imagery and an interactive user experience.

## 📌 Features

* Animated hero section with rotating background images
* Information about the Chief of Defence Staff (CDS)
* Details about:

  * Chief of Army Staff
  * Chief of Air Staff
  * Chief of Naval Staff
* Responsive navigation bar
* Registration page navigation
* Weapons page navigation
* Fixed footer design
* Patriotic theme and user-friendly layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/delta_den.git
```

### Open the Project

Navigate to the project directory:

```bash
cd delta_den
```

### Run the Website

Open `index.html` directly in your browser or use VS Code Live Server.
